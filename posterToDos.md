# Based on Poster Rubric
## [ ] Poster Spec
- [ ] Group Name
- [ ] Project Title
- [ ] zIds of everyone
- [ ] Mentor names
- [ ] Summary of projects content and context
- [ ] Work completed throughout the project e.g.
    - [ ] Lit Review
    - [ ] Description of any implementation work plus coding repos
    - [ ] Description of any experiments conducted
    - [ ] Discussion of results obtained
- [ ] Brief conclusion (interesting take-aways, potential future work) and references (typically 2-4)

## [ ] A Presentation Perspective
- [ ] Uses plenty of figures, visual stimuli and examples
- [ ] Audience members can quickly grasp the concept with context and summary 
- [ ] Key Ideas at a glance
- [ ] Entices questions and people to stop
- [ ] Visual aid for project

## [ ] Presentation 
- [ ] 1-2 minute overview for the topic prepared
- [ ] Q and A prep
- [ ] Supporting document folder / computer folder prepared

## [ ] Bibliography 
- [ ] Complete Reference List
- [ ] Complete In Text References

    - [ ] Clear commmunication of importance
    - [ ] Clear summary reflecting the project content

    - [ ] Describes aspects / main ideas of the project
    - [ ] Visual Support summary of project
    - [ ] Talk abouts specifics more in depth
    - [ ] Not too verbose
    - [ ] Does not lack important aspects
    - [ ] Is clear
    - [ ] Displays the impressive merit of the project
    - [ ] Conveys the key ideas of the project succintly
    - [ ] Great Visual Aid
      - [ ] Engage the audience
      - [ ] Explore aspects of the project more in-depth
      - [ ] Serves to highlight the impressive merit of the project
- [ ] Conclusion / References 3 Marks
    - [ ] Effort to add
    - [ ] Interesting take-aways
    - [ ] Identifies potential future work or open questions
    - [ ] The main relevant references are provided and formatted correctly

    - [ ] Expresses the aim of the project 
    - [ ] Expresses the work completed
    - [ ] The conclusions drawn are clear
    - [ ] The poster is used as a visual aid where adequate
    - [ ] Presentation is engaging and crisp

    - [ ] Able to answer questions 
    - [ ] In-depth answering
    - [ ] Commanding knowledge of the subject matter
